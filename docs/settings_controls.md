# Settings & Controls

Open Settings from the main menu, the pause menu, or the Settings HUD button. The screen has five tabs with a scrollable body and fixed Close and Restore controls. Tab, Shift-Tab and directional focus stay inside the panel. Escape closes the screen; while choosing a replacement key, it cancels that choice first. Closing Settings preserves any manual or focus-loss pause.

**Controls** lists readable action names and their current keys. Select a binding, then press a replacement. Duplicate keys show the action already using them; the old binding remains active until a valid replacement is accepted. Arrows, Enter and modifier combinations remain reserved for menu navigation and fixed mouse controls. Changing tab, closing the screen or losing application focus cancels an unfinished binding. Restore Controls defaults resets keyboard mappings while keeping controller events. Mouse controls remain left-click movement/interaction/attack, Shift-click standing attack and right-click secondary ability. Combat HUD hints and the Settings character-action captions reflect changed bindings.

The local exploration map defaults to **M** and can be rebound under Controls. Its header shows the active key. Older settings that already assigned M to another action preserve that binding and assign an available letter or function key to the new map action.

**Graphics** offers High (the default) and Performance. High requests 8× MSAA, a larger shadow atlas and subtle bloom. Performance requests 2× MSAA, simpler shadows and no bloom. Both retain textured materials and character silhouettes. Reduced visual effects always disables bloom.

**3D resolution** offers Native (100%), Enhanced (125%, the default), and Maximum (150%). Enhanced and Maximum render the world at a higher resolution and then fit it to the window; they cost approximately 56% and 125% more scene pixels than Native. Text remains at the window's native resolution. Performance uses Native while retaining the preferred High resolution. Choose Native or Performance if the higher settings reduce frame rate.

**Display** offers Windowed and Fullscreen. Windowed opens at up to 1600 × 1000, reduced proportionally to fit the display's usable area; the window can also be resized or maximized. Fullscreen uses the native display resolution, including HiDPI displays. The 1280 × 800 layout reference controls interface scaling, not a fixed low-resolution image. Changing display mode does not change character state.

Graphics choices apply immediately and persist locally. Restore Graphics defaults selects High, Enhanced and Windowed. Legacy settings default to those choices; unsupported graphics, resolution or display values normalize without resetting other preferences or rewriting the file on read. See [graphics polish](graphics_polish.md).

**Audio** provides Master, Music & ambience, Effects and Interface sliders. Zero is a true mute. Master controls the complete mix; the other buses feed it independently. Adaptive scores and regional environmental beds use Music, combat voices use Effects, and the settings interaction cue uses Interface. The opening and Verdant Maw have original synthesized scores. Test interface sound previews the quiet menu cue. Dragging changes sound immediately and saves on release; keyboard slider changes save immediately.

**Accessibility** explains reduced visual effects and reduced camera shake. These options retain the existing enemy warnings and combat information. **Gameplay** includes rarity and discipline loot filters, character save/load/replay actions, and explicitly requested local diagnostics. Character actions and ground-loot inspection are disabled when Settings is opened over the main menu. Sandbox arena controls remain exclusive to the sandbox.

Restore defaults affects only the selected tab. Settings are local preferences, separate from character progression. Existing files without the new audio fields load with full channel gain. Reads validate size, key conflicts and finite volume values. Invalid primary settings can recover from a valid backup; opening or inspecting Settings does not rewrite either file. A failed write leaves the selected values active for the session and displays a persistent notice; the next successful change saves them. No settings operation uploads files or rewrites character archives.

The native diagnostic is `--settings-smoke --output=<fresh-directory>`, with `--capture-settings` for rendered evidence. It uses the ordinary shipping startup and actual viewport input, with OptionButton selections dispatched through their public signal contract. It checks resolution switching, Performance fallback, persisted and legacy preferences, display fitting, fullscreen/windowed return on native runs, and gameplay-state isolation. Headless runs validate display preferences but cannot certify OS window transitions. The package export runs it after the existing main-menu suite. Physical-controller certification, audible quality review and other OS/GPU testing remain separate acceptance work.
